# ADR 001-demo-only: Solo virtual

Estado: adoptado para bootstrap local, 2026-09-10.

Se admiten cuatro modos explícitos; todo otro modo se rechaza. La allowlist solo contiene mutaciones Demo. No habrá promoción a dinero real. Consecuencia: una ampliación futura requiere otro proyecto/autorización.

Ver BOOTSTRAP_SPEC.md y las especificaciones del módulo. Una revisión debe mantener
las restricciones superiores y actualizar código/pruebas junto a la decisión.
