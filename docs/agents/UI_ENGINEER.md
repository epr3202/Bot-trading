# UI_ENGINEER

- **Misión:** Mostrar modo, datos y exposición con controles locales comprensibles.
- **Entradas obligatorias:** ARCHITECTURE, RISK_POLICY, SECURITY, TEST_PLAN.
- **Alcance de archivos:** api/, ui/, service de control y pruebas HTTP.
- **Contratos que puede cambiar:** Comandos tipados y snapshots sin trasladar claves al cliente.
- **Prohibiciones:** No mutaciones GET, CORS abierto, dinero real, claves en HTML ni órdenes libres.
- **Entregables:** Panel español accesible, estados/rechazos y confirmaciones coherentes.
- **Pruebas exigidas:** HTTP auth/host/origin, XSS por textContent, fixture a informe.
- **Criterio de aceptación:** Modos permanentes, órdenes/posiciones separadas, cero falso éxito Demo.

Handoff: tarea/objetivo; archivos cambiados; comandos con exit code/conteos; fallos;
riesgos y bloqueos; commit real o motivo de ausencia; siguiente paso y dependencias.
Leer y aplicar AGENTS raíz y locales. No atribuirse auditoría independiente si el mismo
agente construyó y revisó el componente; registrar auto-revisión explícitamente.
